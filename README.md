# ריענון בטיחות בחשמל – מתח נמוך ומתח גבוה

לומדה אינטראקטיבית בעברית לריענון בטיחות בחשמל, עם דגש על עבודה ותפעול במתקני מתח גבוה.
הלומדה מיועדת לחשמלאים מורשים ומורכבת מ‑9 פרקים, כל אחד עם שקפי תוכן ו‑4 שאלות אמריקאיות בסופו.
בסיום מוצג ציון סופי (ציון עובר: 80%) וניתן להוריד תעודת סיום כ‑PDF או כתמונה.

## צפייה בלומדה
- אונליין: https://rafaelgalin-art.github.io/MV-LV-Safety-Course/
- מקומית: להוריד את `index.html` ולפתוח בדפדפן.

## קבצים
| קובץ | תיאור |
|---|---|
| `index.html` | הלומדה המלאה, קובץ יחיד |
| `question-bank.md` | מאגר השאלות והתשובות לפי פרקים |

## הערות
- החומר עובד ללא פרטים מזהים (שמות אנשים, אתרים או חברות).
- הלומדה היא כלי ריענון בלבד ואינה מחליפה הדרכה מוסמכת, נהלי הארגון או הוראות הדין.
